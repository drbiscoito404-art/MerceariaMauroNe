# Mercearia Mauro Né

Este repositório contém o projeto completo da mercearia.

- server.js: backend Express que serve a API e os arquivos estáticos.
- public/: arquivos do site estático (index.html, style.css, script.js).
- package.json: defines script to run the server.

A branch gh-pages contém o site estático publicado para GitHub Pages.
